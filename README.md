# Crazy Kingdom 🎮

Crazy Kingdom is a Python game built using Pygame.

## Features

- Interactive gameplay built with Pygame.
- Game graphics and assets included in the repository.
- Simple setup using Python and pip.

## Requirements

- Python 3
- Pygame

## Installation

### 1. Clone the repository

Open a terminal and run:

```bash
git clone https://github.com/arnavtikole/Crazy-Kingdom.git
```

### 2. Navigate to the project folder

```bash
cd Crazy-Kingdom
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Run the game

```bash
python crazykingdom.py
```

## Technologies Used

- **Python** — Game logic and programming.
- **Pygame** — Graphics, input handling, and game functionality.

## Getting Started

Make sure Python is installed on your computer before following the installation instructions. Keep the asset folders in their original locations so the game can access its resources.

Have fun playing Crazy Kingdom!
